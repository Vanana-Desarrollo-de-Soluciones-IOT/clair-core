# Historias de Usuario - Analíticas (Analytics)

Esta sección presenta las Epics e Historias Técnicas identificadas para el módulo de Analíticas (Analytics).

## Epics

| Epic / Story ID | Título | Descripción | Criterios de Aceptación | Relacionado con (Epic ID) |

| EPIC-01         | Visualización de Métricas y Analítica | Como Usuario, quiero visualizar métricas en tiempo real e históricas de mis dispositivos, para poder analizar el comportamiento de mi entorno e identificar tendencias. | La Epic se completa cuando todas las historias de usuario relacionadas han sido implementadas, validadas y aceptadas. | - |

## Historias Técnicas

| Epic / Story ID | Título | Descripción | Criterios de Aceptación | Relacionado con (Epic ID) |
| --------------- | ------ | ----------- | ----------------------- | ------------------------- |
| TS-01           | Obtener Métricas en Tiempo Real | Como Desarrollador, quiero obtener las métricas clave de rendimiento en tiempo real a través de una API, para poder renderizar inmediatamente los valores de telemetría en el panel de control. | Escenario: Obtener métricas KPI en vivo exitosamente<br>Dado que el endpoint "/api/v1/analytics/devices/{deviceId}/live" está disponible<br>Cuando se envía una petición GET con un `deviceId` existente<br>Entonces se recibe una respuesta con estado 200 conteniendo los datos de telemetría en vivo.<br><br>Escenario: Intentar obtener métricas en vivo sin telemetría disponible<br>Dado que el endpoint "/api/v1/analytics/devices/{deviceId}/live" está disponible<br>Cuando se envía una petición GET con un `deviceId` que no tiene registros de telemetría recientes<br>Entonces se recibe una respuesta con estado 404. | EPIC-01 |
| TS-02           | Transmitir Telemetría en Vivo mediante SSE | Como Desarrollador, quiero establecer un canal de Server-Sent Events (SSE) para un dispositivo a través de una API, para transmitir flujos de datos en tiempo real al navegador. | Escenario: Establecer transmisión SSE exitosamente<br>Dado que el endpoint "/api/v1/analytics/devices/{deviceId}/live/stream" está disponible<br>Cuando se inicia una conexión GET con tipo de medio `text/event-stream`<br>Entonces se recibe una respuesta con estado 200 y el canal SSE queda establecido. | EPIC-01 |
| TS-03           | Obtener Métricas Históricas | Como Desarrollador, quiero consultar métricas de rendimiento históricas agrupadas por períodos a través de una API, para permitir análisis retrospectivos del entorno físico. | Escenario: Obtener métricas históricas del dispositivo<br>Dado que el endpoint "/api/v1/analytics/devices/{deviceId}/historical" está disponible<br>Cuando se envía una petición GET con los parámetros de consulta `period`, `startDate` y `endDate`<br>Entonces se recibe una respuesta con estado 200 y los KPI agregados del rango solicitado.<br><br>Escenario: Consulta histórica con rango de fechas inválido<br>Dado que el endpoint "/api/v1/analytics/devices/{deviceId}/historical" está disponible<br>Cuando se envía una petición GET donde `startDate` es cronológicamente posterior a `endDate`<br>Entonces se recibe una respuesta con estado 400. | EPIC-01 |
| TS-04           | Obtener Tendencias Históricas del Dispositivo | Como Desarrollador, quiero recuperar series temporales de datos históricos de un dispositivo a través de una API, para alimentar los gráficos de tendencias temporales en el frontend. | Escenario: Obtener puntos de tendencia temporal para gráficos de forma exitosa<br>Dado que el endpoint "/api/v1/analytics/devices/{deviceId}/trends" está disponible<br>Cuando se envía una petición GET con parámetros `period`, `startDate`, `endDate` y `limit`<br>Entonces se recibe una respuesta con estado 200 con la serie cronológica de puntos de datos.<br><br>Escenario: Consulta de tendencias con fechas incorrectas<br>Dado que el endpoint "/api/v1/analytics/devices/{deviceId}/trends" está disponible<br>Cuando se envía una petición GET donde `startDate` es posterior a `endDate`<br>Entonces se recibe una respuesta con estado 400. | EPIC-01 |
| TS-05           | Obtener Resumen General de Analíticas | Como Desarrollador, quiero obtener una vista global unificada de espacios, dispositivos y alertas recientes a través de una API, para renderizar la página principal del dashboard del usuario. | Escenario: Recuperar resumen general del dashboard exitosamente<br>Dado que el endpoint "/api/v1/analytics/overview" está disponible<br>Cuando se envía una petición GET por parte de un usuario autenticado con los parámetros opcionales `deviceLimitPerSpace` y `alertLimit`<br>Entonces se recibe una respuesta con estado 200 conteniendo el desglose general de espacios, estados de dispositivos y últimas alertas. | EPIC-01 |
